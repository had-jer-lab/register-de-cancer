📊 DONNÉES EXPORTÉES
═══════════════════════════════════════════════════════════════════════════════

8 colonnes:
  1. Wilaya           - Province (ex: Tlemcen)
  2. Daira            - District/Commune (ex: Mansourah)
  3. Nombre_Cas       - Total cancers (ex: 84)
  4. Homme            - Patients masculins (ex: 50)
  5. Femme            - Patients féminins (ex: 34)
  6. Age_Moyen        - Âge moyen (ex: 52.4)
  7. Cancer_Dominant  - Type le + fréquent (ex: Sein)
  8. Annee            - Année diagnostic (ex: 2023)

Format: CSV UTF-8 avec BOM (Excel-ready)
Nommage: registre_cancer_daira_statistics_YYYY-MM-DD.csv

🔌 API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

GET /api/patients/export/daira-statistics/
  Paramètres: year=2023, wilaya=Tlemcen
  Retour: JSON avec données par daira

GET /api/patients/export/wilaya-statistics/
  Paramètres: year=2023
  Retour: JSON avec données par wilaya

GET /api/patients/export/metadata/
  Paramètres: Aucun
  Retour: {years, wilayas, total_cases}


❌ TROUBLESHOOTING RAPIDE
═══════════════════════════════════════════════════════════════════════════════

Problème: "API not found" (404)
→ Vérifier: backend/patients/urls.py a les 3 routes export/*

Problème: CSV vide
→ Vérifier: Données existent en DB
   $ python manage.py shell
   >>> from patients.models import Cancer
   >>> Cancer.objects.count()  # Should be > 0

Problème: Caractères corrompus
→ Fichier utilise UTF-8 BOM (normal) - Excel reçoit OK

Problème: Pas de téléchargement
→ DevTools F12 → Network → vérifier GET status 200
